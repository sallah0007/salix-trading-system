# SALIX Type-1 canonical identity content import boundary

This branch does not invent or reconstruct feature definitions.

A population run may only import rows supported by an explicit source manifest.

Key fence:

- MECHANISM_COMPLETE != CANONICAL_CONTENT_POPULATED
- ZERO IMPORTABLE ROWS != PROOF OF ABSENCE
- population_complete may be TRUE only when the governed source universe is declared complete, every source is searched/dispositioned, unresolved source classes are empty, row counts reconcile, and the stale-state sweep passes.

Current SALIX evidence does not yet prove a complete source universe for the historical populated registry / feature-definition catalogue. Therefore the current real population state remains incomplete even if zero rows are importable from the presently located documents.

# R53 — independent row-step verification bound to row acceptance

CODER FINDING != SALIX DECISION. Merge/CI clears no gate. All profile/step/codec/input instances in tests are SIM and UNADMITTED.
**Gap closed (engineering).** Producer==independent byte-hash equality does not show the proposed state is the declared legal successor. `tracker/verification/row_step_verifier.verify_row_step` (stdlib + own modules only; own shape/finite/projection logic, no import of state_rows) re-reads the actual inputs through a supplied resolver, decodes the exact predecessor tuple (must be canonical), re-derives the successor through a supplied INDEPENDENT reference step and codec, and compares state-tuple bytes and projection bits; it also checks row-hash recomputation, predecessor hash/step_index/identity linkage and origin-xor-predecessor. Unreadable inputs = INSUFFICIENT_EVIDENCE (never PASS); a failing/raising supplied port = FAIL. Result is a typed, scope-qualified `VerificationResult` (scope COMPONENT_ROW_STEP_V1, candidate) issued through the existing verifier-run receipt path.
**Binding.** `RowAcceptor.accept` now requires that result: issued by a verifier run, scope ROW_STEP (existing `require_pass`), PASS, subject names THIS row, and the evidence ref's hash is that result's hash. Tests refuse another row's genuine PASS, a ref naming another result or none, a hand-built same-checks result, a materialization-scope result with a receipt, and a FAIL result; nothing is accepted by any refusal.
**Limits (stated in the result subject).** The input VALUE hash rule is not defined, so inputs are bound by the declared (ref, hash) pairs the resolver echoes (`INPUT_VALUE_HASH_RULE_NOT_DEFINED_BINDING_BY_DECLARED_REF_HASH_ONLY`). The receipt is an in-process label, not a security boundary. Held: the real profile's reference step/codec instances, input resolver over actual stored inputs, principals, time, commit-point rule. Equivalent/shadowed mutant: the origin-xor check is shadowed by the supplied independent row-hash port, which applies the Annex origin rule itself.
**Mutants killed:** state compare, projection bits, step index, identity fields, predecessor hash, predecessor canonical bytes, inputs bound, insufficient-evidence path, row hash, plus four evidence-binding mutants in the acceptor.

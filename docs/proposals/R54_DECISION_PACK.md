(d) Options for the PROGRAM GRAMMAR (item 2):

Defect: an operand stack evaluates operands before the operator sees them, so an unselected `select` branch would be EVALUATED (and could fail a domain check) - this contradicts the implemented lazy select, where an invalid unselected branch must not force evaluation.

Keeps laziness and static verifiability.
 - O3 node-graph encoding (the manifest `nodes` order, topologically sorted, operands by node id) with `select` evaluated lazily by node reachability. Closest to the existing manifest and incremental evaluator.
